# Restaurant Explorer and Ordering Platform

This workspace contains the Ocean Eats food ordering frontend built with Next.js.

- Container: food_ordering_frontend
- Purpose: Browse restaurants, view menus, manage cart, place orders
- Style: Ocean Professional (Blue & Amber accents)
- Start: change into the container and run `npm install` then `npm run dev`.

Refer to food_ordering_frontend/README.md for detailed instructions.
